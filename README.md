# محاضرة: الكسوف الكلي للشمس — ٢ أغسطس ٢٠٢٧

محاضرة تأهيلية للمرشدين السياحيين والأثريين، مدتها **ثلاث ساعات** في **ثلاث مراحل**، بالعربية مع المصطلحات بالإنجليزية.

**الملف:** [`محاضرة_الكسوف_الكلي_2027.pptx`](محاضرة_الكسوف_الكلي_2027.pptx). يضم ٦٧ شريحة، ولكل شريحة ملاحظات المحاضر (Speaker notes) فيها الشرح التفصيلي.

## المصادر

- كتاب «الكسوف الكلي للشمس — ٢ أغسطس ٢٠٢٧»، في المستودع `eclipse`: منه الأشكال والجداول والأوقات.
- رواية «أرصاد وأطوار»: أُخذت منها الأحداث الفلكية التي يصفها ملحق المؤلف بأنها تاريخية، مع نصوص ابن يونس.
- حسابات جديدة أُجريت لهذه المحاضرة بأدوات الكتاب نفسها:
  - كسوف ٢٧ يناير ٦٣٢م في المدينة المنورة.
  - خسوفات ٢٠٢٨–٢٠٣٠ كما تُرى من القاهرة.
  - وقت الزوال يوم الكسوف.
  - شكل الشمس في الأقصر لحظةً بلحظة (`build/luxor_phases.json`).
