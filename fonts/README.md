# Fonts

The deck uses three free fonts (SIL Open Font License 1.1):

| Font | Used for | Source |
|---|---|---|
| Amiri (Regular, Bold) | Arabic titles and large numbers | Khaled Hosny, via @fontsource/amiri (subsets merged into one file) |
| Noto Naskh Arabic (Regular, Bold) | Arabic body text | Google Noto |
| EB Garamond (Regular, Bold, Italic) | English text | Georg Duffner, via @fontsource/eb-garamond (Latin subset) |

Install them before editing the `.pptx`; the PDF and picture copies already carry them.
